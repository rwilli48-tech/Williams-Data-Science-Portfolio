### 3. Supervised Machine Learning Streamlit App  
Repository:

Live App:  
https://williams-data-science-portfolio-cagjavu9kxwxtvdvbkns37.streamlit.app/

### 4. Unsupervised Learning Streamlit App  
Repository:  
https://github.com/rwilli48-tech/Williams-Data-Science-Portfolio/tree/main/MLUnsupervisedApp/README.md

Live App:
https://rwilli48-tech-williams-data-scienc-mlunsupervisedappmain-lkybxg.streamlit.app/

* This project extends my machine learning work into unsupervised learning by allowing users to explore clustering and pattern discovery without predefined labels.  
* The app enables users to upload datasets, apply techniques such as clustering (e.g., K-Means), and visualize how observations group together based on underlying structure.  
* It builds on my previous supervised learning app by shifting the focus from prediction to **discovery**, highlighting how machine learning can uncover hidden patterns in data.

## Portfolio Development & Integration

This portfolio is designed to showcase both technical skills and practical application of data science concepts.

* The **Supervised ML App** demonstrates my ability to build end-to-end predictive workflows.
* The **Unsupervised ML App** complements this by showing how I can extract insights when labeled outcomes are not available.
* Together, these projects highlight my ability to:
  - Develop interactive Python applications using Streamlit  
  - Implement machine learning models using real-world datasets  
  - Deploy working tools that others can use and explore  

These projects also reflect my growing focus on **user-facing data science**, where models are not just built, but made accessible and interpretable.
